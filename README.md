This repository contains my solutions for Lab 3 on Feedforward Neural Networks. The lab explores how neural networks learn from data, how hidden layers improve model performance, and how to train models using both manual backpropagation and PyTorch.

## Objectives

- Build a simple neural network from scratch using NumPy.
- Understand forward propagation and backpropagation.
- Explore the effect of hidden layers and activation functions.
- Train a neural network using PyTorch.
- Compare model performance using training and validation results.
